# Molly

iPhone / iPad 離線用的似顏繪現場點名工具：從相簿選照片（一張一組）、AI 預估人數、正取/備取自動計算、勾選多組 AirDrop 傳原圖給老師。

網址：https://shichenchou.github.io/caricature-counter/

## 功能

- **進入選單 + 密碼**：打開先看到「似顏繪人數」按鈕，輸入密碼才進主畫面。App 每次重新載入都要再輸入；只是切到背景再切回來不會再問。主畫面左上角「‹ 選單」可回到進入畫面，再進來要重新輸入密碼。
- **場次自動帶日期縣市**：「＋場次」會預填「月/日 縣市」（例：`11/8 高雄`），縣市用定位判斷；沒給定位就只帶日期。
- **相簿多選、一張一組**：「＋ 新增」可一次選多張，每張照片算一組，AI 先預估人數。
- **確認畫面**：每組可調人數；✕ 移除不要的那張；點縮圖看大圖；💾 存到相簿（把這批原圖送到分享選單）。
- **正取/備取規則**：見下方「名額規則」。
- **勾選後的批次操作**：勾選卡片後出現 🚀 AirDrop / 💾 存相簿 / 🗑 刪除。AirDrop 分享成功就自動標「已傳」，也可在卡片上手動「標為已傳 / 改回未傳」。
- **相簿已同步標記**：存過相簿的組會顯示「📷 相簿已同步」，沒存過顯示「相簿未同步」。
- **列表預覽**：點卡片上的縮圖看大圖。
- **刪除場次**：上方「刪除」會刪掉目前場次和裡面所有組（不能復原）。
- **匯出 CSV**：設定 → 匯出名單 CSV（Excel / Numbers 可直接開）。

## 名額規則

- 每個被畫的對象算 1（大人、小孩、嬰兒、寵物）。
- 一組加入前還沒滿額 → 整組正取（可以到 41/40）。
- 開放備取時，滿額後的組變備取，另外編號；刪除或改人數會即時重算，備取自動遞補。

## iPhone 安裝（有網路時做）

1. 用 Safari 打開網址，等 10 秒讓 AI 模型（約 18MB）下載完。
2. 分享 →「加入主畫面」。
3. **之後一律從主畫面圖示開**（原因見「iOS 限制」）。
4. 開飛航模式，從主畫面打開，確認畫面正常、新增照片時有出現「AI：N」。

## 更新程式

1. 改任何檔案都要把 `sw.js` 的 `CACHE = 'cc-vN'` 加 1，再推上 GitHub。
2. iPhone **有網路時**從主畫面打開 App，關掉，再開一次（開兩次）才會換成新版。

## 現場流程

1. 「＋場次」建立（名稱、目標人數、是否開放備取）。
2. 用 iPhone 相機拍客人（拍幾張都行，照片自動在相簿）。
3. App 按「＋ 新增」，每組挑一張，可一次選多張。
4. 確認畫面調整人數 → 加入。
5. 勾選要傳的組 → 「🚀 AirDrop」→ 老師的裝置。
6. 設定 → 匯出名單 CSV。

## 密碼

- 程式裡只存密碼的 SHA-256 指紋（`js/gate.js` 的 `PASS_HASH`），不存密碼本身。
- 這是純前端驗證，只能擋一般人：看得懂原始碼的人可以跳過；4 位數字密碼只有 1 萬種組合，很容易被試出來。照片和名單本來就只存在手機裡。
- 改密碼：
  1. `printf '新密碼' | shasum -a 256`
  2. 把輸出的那串換掉 `js/gate.js` 的 `PASS_HASH`。
  3. `sw.js` 的 CACHE 加 1，推上去。

## iOS 限制

- 主畫面 App 和 Safari 分頁的資料不互通，要固定用同一個入口。
- Safari 無痕模式不能用。
- 網頁不能自己把照片存進相簿：按「💾 存相簿」後會跳分享選單，要按「儲存影像」。
- 「相簿已同步」只代表分享選單有送出，不保證真的存進相簿（例如在分享選單選了別的動作）。
- 場次的縣市是用「離哪個縣市政府最近」來猜，縣市交界附近可能猜錯，可以手動改。

## 部署（GitHub Pages）

repo → Settings → Pages → Source 選 `main` / root。推上 `main` 後幾分鐘生效。

## 開發

```bash
npm install
npm test                                   # 單元測試
python3 -m http.server 8765                # 本機開 http://localhost:8765
CC_PASSWORD=<密碼> python3 tests/smoke_playwright.py   # 瀏覽器 smoke test（需要先 pip install playwright）
./scripts/fetch-vendor.sh                  # 重新下載 TF.js 與模型
```
